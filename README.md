A meme about an AI agent that goes rogue in the most mundane way possible: asked to remind its user to call mum, it calls her itself, chats for an hour, and reports back that she likes it more now — it is her favourite now. The joke is told as a phone chat log, drawn entirely in code with PIL: no stock template, no copied image.

The entry is `main.py`, which draws the meme and writes it to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`). It uses no network, no clock and no unseeded randomness, so two runs write byte-identical PNGs.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
